# GamePulse 2025 – Data Pipeline & AI Sentiment Rating

`gamepulse_pipeline.py` collects 2025 game data (IGDB, RAWG, Steam, Xbox), picks the top 10 free and top 10 paid
Steam games by review volume, cleans their reviews, and gives every review an **AI sentiment score from 0 to 100**
(plus a 1–5 rating). Every game is also backfilled with a **developer** (a.k.a. creator / studio).

## 1. Requirements

- Windows, macOS or Linux with **Python 3.10+** (tested on 3.12). Download from <https://www.python.org/downloads/>.
- Internet access (the script calls public APIs).
- Free API keys (see step 3).

## 2. Set up the environment

From the `AI Development` folder:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1          # macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
```

`requirements.txt` installs `requests`, `pandas`, `python-dotenv` and `vaderSentiment` (the sentiment model; no
separate model download is needed).

## 3. Get API keys and create `.env`

Copy `.env.example` to `.env` (same folder as the script) and fill in:

| Variable | Where to get it |
|---|---|
| `RAWG_API_KEY` | Free key at <https://rawg.io/apidocs> |
| `IGDB_CLIENT_ID`, `IGDB_CLIENT_SECRET` | Register an app at <https://dev.twitch.tv/console> (needs Twitch 2FA), then copy the Client ID and generate a Client Secret |

Never commit `.env` (it is git-ignored). Steam requires no key.

## 4. Input data (`Data CSVs/`)

| File | Status |
|---|---|
| `igdb-games-2025.csv`, `rawg-games-2025.csv` | Regenerated by the script from the APIs (included for convenience) |
| `xbox-games-2025.csv` | **Required** (columns: rank, title, store_id, release_date, average_rating, rating_count) |
| `xbox-games-2025-written-reviews.csv` | Optional Xbox Store written reviews (columns: store_id, review_id, review_date, review_title, review_text, review_rating, votes_up, votes_down); matched to the catalog by `store_id`; skipped with a warning if absent |
| `steam 2025.csv` | Optional supplemental Steam reviews; skipped with a warning if absent |

`Files.zip` holds a copy of these CSVs and the raw API cache.

## 5. Run

```powershell
python gamepulse_pipeline.py
```

- Raw API responses are cached in `data/raw/`, so re-runs are fast and resumable. Delete that folder to force a
  fresh pull. Unzipping `Files.zip` here restores the cache.
- A first run with an empty cache can take **1–2 hours** (rate-limited developer lookups for thousands of games).

## 6. Outputs (`output/`)

| File | Contents |
|---|---|
| `gamepulse_games_clean.csv` | Catalog of games with `developers`, `developer_source`, the genre columns and per-game sentiment columns (blank for games without reviews) |
| `gamepulse_reviews_clean.csv` | Cleaned Steam and Xbox reviews with sentiment columns and the game's genre columns. Steam rows carry `steam_appid`; Xbox rows carry `xbox_store_id`, `review_title`, `review_star_rating` and `votes_down` |
| `gamepulse_game_summary.csv` | One row per reviewed game (Steam or Xbox) with aggregated sentiment/trust metrics |
| `cleaning_log.csv` | How many reviews each cleaning step removed |
| `games_missing_developer.csv` | Games where no developer could be found (e.g. Xbox titles; the Xbox CSV has no developer column) |
| `games_missing_genre.csv` | Games where no genre could be found (only written when some remain) |

### Genres

Genre names differ by source (IGDB "Role-playing (RPG)", RAWG "RPG", Steam "Free To Play"), so they are mapped onto one
shared list of 26 genres (Action, Adventure, RPG, Strategy, Simulation, Shooter, Platformer, Sports, …). Steam's
non-genre labels such as "Free To Play" and "Early Access" are dropped.

- `genres` – the game's genres, `; `-separated.
- `primary_genre` – the first genre; `genre_count` – how many genres the game has.
- `genre_action`, `genre_rpg`, `genre_platformer`, … – one column per genre, `1` if the game has it, else `0`.
- `genre_source` – where the genre came from (`catalog`, `steam`, `rawg_detail`, `igdb_search`, `rawg_search`).

Genre lookup order for games with no genre: Steam → RAWG detail → IGDB title search → RAWG title search.

### The AI rating

Each review is split into clauses (at punctuation and contrast words such as "but"). VADER, extended with a gaming
lexicon (e.g. "buggy", "p2w", "goated"), scores each clause; positive and negative strength offset each other.

- `sentiment_score_100` – 0 (very negative) to 100 (very positive); balanced reviews land near 50.
- `sentiment_rating` / `sentiment_category` – 20-point bands: 1 Very Poor, 2 Poor, 3 Mid, 4 Good, 5 Very Good.
- `sentiment_mixed`, `sentiment_positive_share`, `sentiment_negative_share` – mixed-opinion indicators.
- `sentiment_label` – the reviewer's own vote: Steam thumbs up/down, or for Xbox reviews 4–5 stars = `positive`,
  1–2 = `negative`, 3 = `neutral`. In `gamepulse_games_clean.csv` the seven sentiment columns are rolled up per game
  (majority vote, mean score, summed positive/negative shares).
- `vote_text_mismatch` – the reviewer's vote (Steam thumb or Xbox stars) contradicts the review's tone.
- `short_playtime_flag` – under 1 hour played at review time (review-bomb check); blank when playtime is unknown
  (all Xbox reviews).

### Developer lookup order

Catalog data → Steam → RAWG detail → IGDB title search → RAWG title search → RAWG development-team credits.

## 7. Sentiment validation (held-out split)

`python sentiment_validation.py` (add `--refresh-sample` to rebuild the Xbox rows of the sample) writes
`output/sentiment_validation_split.csv`, `sentiment_validation_results.csv` and `sentiment_validation_summary.csv`.

**Sample** (`gamepulse_sentiment_validation_sample.csv`, 1,100 reviews): 500 Steam reviews (AI-assigned
positive/negative/neutral/mixed labels, not human-verified) + 600 Xbox written reviews drawn class-balanced
(200 each of 4–5★, 3★, 1–2★) and labeled by the reviewer's stars (a proxy; Xbox has no "mixed" ground truth). A
plain random Xbox draw is ~64% positive with few 3★ rows, so it was rebalanced to leave enough neutral rows to test.

**Split:** 748 train / 132 validation / 220 held-out test (about 68/12/20), seed 42, stratified by platform + label,
made before any fitting and recorded per review in `sentiment_validation_split.csv`. TF-IDF is fit on train only. The
validation slice is never trained on; it logs `val_loss`/`val_accuracy` every epoch in
`sentiment_validation_results.csv` and is used to choose the epoch count. The test rows are scored once at the end.

**Epochs: 30.** At 10 epochs the sigmoid network had not learned (it predicted "positive" for everything). On the
validation slice, relu/linear reach their lowest loss at epoch 22 and sigmoid at epoch 30, with overfitting beyond
that (train accuracy ≈ 0.99 vs validation ≈ 0.73), so 30 is a compromise that is fair to all three.

**Results on the 220 held-out reviews** (NN trained 30 epochs on the 533 train positive/negative rows and scored on
the 156 test positive/negative rows):

| Model | Accuracy | Precision | Recall | F1 |
|---|---|---|---|---|
| NN, relu | 0.782 | 0.796 | 0.848 | 0.821 |
| NN, linear | 0.782 | 0.790 | 0.859 | 0.823 |
| NN, sigmoid | 0.808 | 0.772 | 0.957 | 0.854 |
| VADER pipeline, binary (score ≥ 50) | 0.763 | 0.739 | 0.924 | 0.821 |
| VADER pipeline, 3-class (≥60 / 40–60 / <40), macro | 0.586 | 0.608 | 0.556 | 0.556 |

**Role of mixed/neutral examples.** The network is binary, so neutral and mixed reviews are never used to train it or
to compute its precision/recall; forcing them into either class would teach it noise. They stay in the held-out split
and test the VADER pipeline's middle band: of held-out reviews, 54% of neutral and 45% of mixed land in the mid band
(score 40–60), against 16% of positive; mean scores are positive 74, neutral 56, mixed 62, negative 49. Mixed/neutral
reviews therefore sit between the polarities as intended, but only partly: many are still pushed to a side.

**Separate VADER pipeline.** `gamepulse_pipeline.py` scores every review with clause-level VADER plus a gaming lexicon
(no training, no labels), producing `sentiment_score_100`, ratings and the `sentiment_mixed` flag used in the outputs.
The neural network is only a validation experiment and does not feed those outputs. VADER is evaluated on the same
test rows. It is competitive with the network on positive-vs-negative (F1 0.82 vs 0.82–0.85) but weak on negatives
(3-class negative recall 0.36, mean negative score 49): complaints are often phrased neutrally or with sarcasm.

Caveats: ~156 binary test rows give roughly ±7 points of uncertainty, so the differences between the three
activations and VADER are not statistically meaningful; the validation slice is small (94 binary rows), so the
chosen epoch count is approximate; labels are proxies, not human annotation.

## Troubleshooting

- **"RAWG_API_KEY" / IGDB errors** – check `.env` is in the same folder as the script and has no quotes or spaces.
- **`steam 2025.csv` not found** – expected; the file is optional.
- **HTTP errors for odd titles** – non-fatal; the script retries and moves on.
- **PowerShell blocks activation** – run `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`, or call
  `.\.venv\Scripts\python.exe gamepulse_pipeline.py` directly.
